# Tiendas Drakkar

Production-ready foundation for the Tiendas Drakkar commercial platform.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- ESLint
- Prettier
- Prisma
- PostgreSQL
- Docker Compose

## Project boundaries

- `src/frontend`: reusable UI foundation.
- `src/backend`: API and server-side service boundaries.
- `src/shared`: shared configuration, types, and utilities.
- `prisma`: database schema and migrations.
- `infra`: Docker and infrastructure configuration.
- `scripts`: operational scripts.
- `public`: static assets.
- `docs`: product, business, architecture, and development documentation.

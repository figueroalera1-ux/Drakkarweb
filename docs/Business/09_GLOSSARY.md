# GLOSSARY

Versión: 1.0

---

# Objetivo

Este documento define los términos oficiales utilizados en Tiendas Drakkar.

Todos los desarrolladores, agentes de IA, automatizaciones y documentación deberán utilizar estas definiciones para evitar ambigüedades.

---

# Lead

Persona que muestra interés en uno o más productos y proporciona datos de contacto.

---

# Cliente

Persona o empresa que ha realizado al menos una compra confirmada.

---

# Distribuidor

Persona o empresa autorizada para comercializar productos de Tiendas Drakkar bajo condiciones de mayoreo.

---

# Producto

Artículo comercializado por Tiendas Drakkar.

Puede tener variantes de color, medidas y configuración.

---

# Variante

Versión específica de un producto que modifica alguna característica sin cambiar el producto principal.

---

# SKU

Código único utilizado para identificar un producto o una variante.

---

# Categoría

Agrupación de productos con características similares.

---

# Pedido

Solicitud confirmada realizada por un cliente.

Un pedido puede contener uno o varios productos.

---

# Producción

Proceso de fabricación de un pedido confirmado.

---

# Entrega

Proceso mediante el cual un pedido terminado es entregado al cliente.

---

# CRM

Sistema utilizado para administrar clientes, Leads, ventas y seguimiento comercial.

---

# CMS

Sistema utilizado para administrar el contenido del sitio web.

---

# Pipeline

Conjunto de etapas comerciales por las que pasa un Lead hasta convertirse en cliente.

---

# Automatización

Proceso ejecutado automáticamente por el sistema sin intervención manual.

---

# Agente IA

Sistema basado en Inteligencia Artificial encargado de asistir en tareas específicas respetando las reglas del negocio.

---

# Dashboard

Panel que concentra indicadores, métricas y resúmenes operativos para facilitar la toma de decisiones.

---

# KPI

Indicador utilizado para medir el desempeño de un proceso o área del negocio.

---

# Fuente de Lead

Canal por el cual llegó un cliente potencial.

Ejemplos:

Sitio web.

WhatsApp.

Facebook.

Instagram.

TikTok.

Referido.

Publicidad.

---

# Estado

Situación actual de un proceso, pedido, Lead o producción dentro del sistema.

---

# Cobertura

Zona geográfica donde Tiendas Drakkar ofrece servicio de entrega directa.

---

# Documento vivo

Toda la documentación del proyecto podrá evolucionar conforme crezca la empresa.

Las modificaciones deberán registrarse y versionarse para mantener consistencia en todo el sistema.

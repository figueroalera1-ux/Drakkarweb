# PRODUCTION PROCESS

Versión: 1.0

---

# Objetivo

Este documento define el proceso de producción de Tiendas Drakkar.

Su propósito es establecer las reglas para fabricar los productos solicitados por los clientes de manera organizada y controlada.

---

# Filosofía

La producción estará orientada principalmente a pedidos confirmados.

No se fabricará inventario de manera masiva salvo autorización expresa de la empresa.

Cada pedido deberá poder rastrearse desde su creación hasta su entrega.

---

# Flujo de Producción

Pedido confirmado

↓

Validación del pedido

↓

Asignación a producción

↓

Fabricación

↓

Control de calidad

↓

Producto terminado

↓

Programación de entrega

↓

Entrega al cliente

---

# Inicio de Producción

La producción únicamente iniciará cuando:

- El pedido esté confirmado.
- La información del producto sea correcta.
- El color esté validado.
- La configuración esté validada.
- Exista autorización para fabricar.


---

# Estados de Producción

Pendiente.

Programado.

En fabricación.

Control de calidad.

Terminado.

Listo para entrega.

Entregado.

Cancelado.

---

# Control de calidad

Antes de entregar un producto deberá verificarse:

- Modelo correcto.
- Color correcto.
- Configuración correcta.
- Estado físico.
- Limpieza.
- Accesorios.

---

# Información registrada

Cada orden de producción deberá almacenar:

- Número de pedido.
- Cliente.
- Producto.
- Variante.
- Color.
- Fecha de inicio.
- Fecha estimada.
- Fecha de finalización.
- Estado.
- Observaciones.

---

# Automatización futura

El sistema permitirá:

- Crear automáticamente órdenes de producción.
- Actualizar estados.
- Notificar al cliente.
- Notificar al asesor.
- Registrar tiempos de fabricación.
- Generar estadísticas de producción.

---

# Criterios de aceptación

El proceso de producción deberá permitir conocer en todo momento el estado de fabricación de cualquier pedido y servir como base para futuras automatizaciones.

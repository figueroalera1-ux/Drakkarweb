# PRODUCT RULES

Versión: 1.0

---

# Objetivo

Este documento define todas las reglas relacionadas con los productos de Tiendas Drakkar.

Estas reglas deberán ser utilizadas por:

- Sitio Web.
- Catálogo.
- CMS.
- CRM.
- Automatizaciones.
- Agentes de IA.
- API.
- Base de datos.

---

# Filosofía

Los productos son el activo principal de Tiendas Drakkar.

Toda la información deberá mantenerse organizada, actualizada y consistente.

Nunca deberán existir productos duplicados ni información contradictoria.

---

# Identificación

Cada producto deberá tener:

- ID único.
- SKU único.
- Nombre comercial.
- Categoría principal.
- Estado.

---

# Estados del producto

Borrador.

Publicado.

Oculto.

Descontinuado.

Agotado temporalmente.

---

# Categorías iniciales

Salas.

Sofás cama.

Reposets.

Recámaras.

Sillas.

Comedores.

Complementos.

---

# Variantes

Un producto podrá tener múltiples variantes.

Las variantes podrán cambiar:

- Color.
- Medidas.
- Configuración.
- Precio.
- Fotografías.

Cada variante conservará la relación con el producto principal.

---

# Fabricación

Los productos se fabricarán principalmente sobre pedido.

El tiempo estimado de fabricación podrá modificarse sin alterar el producto.

---

# Fotografías

Cada producto podrá tener:

Imagen principal.

Galería.

Imagen de medidas.

Imagen de colores.

Imagen en ambiente.

---

# Colores

Cada producto mostrará únicamente los colores disponibles.

Un color podrá utilizarse en varios productos.

---

# Productos relacionados

Cada producto podrá relacionarse con otros productos similares.

Estas relaciones podrán administrarse manualmente.

---

# Producto destacado

Un producto podrá marcarse como destacado.

Los productos destacados podrán mostrarse automáticamente en distintas áreas del sitio.

---

# SEO

Cada producto tendrá:

URL amigable.

Meta Title.

Meta Description.

Open Graph.

Schema.org Product.

---

# Administración

Toda la información del producto deberá poder modificarse desde el CMS.

No será necesario modificar el código fuente.

---

# Criterios de aceptación

Este documento estará completo cuando defina todas las reglas necesarias para administrar el catálogo de Tiendas Drakkar.

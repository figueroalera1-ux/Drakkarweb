# PAGE PRODUCTO

Versión: 1.0

---

# Objetivo

La página de producto será la página más importante para la conversión.

Su objetivo será resolver todas las dudas del cliente antes de que contacte a un asesor.

Cada producto tendrá su propia URL optimizada para SEO.

No se utilizarán ventanas modales para mostrar información importante.

---

# Objetivos comerciales

La página deberá:

• Mostrar claramente el producto.

• Generar confianza.

• Explicar medidas y características.

• Mostrar los colores disponibles.

• Resolver dudas frecuentes.

• Facilitar el contacto por WhatsApp.

# Galería del producto

## Objetivo

La galería será el principal elemento de decisión del cliente.

Las fotografías deberán mostrar el producto con la mayor fidelidad posible.

---

## Contenido

Cada producto podrá tener:

- Imagen principal.
- Imágenes secundarias.
- Fotografías de detalle.
- Fotografías del producto en ambiente.
- Imagen de medidas.
- Imagen de colores disponibles.

---

## Funcionalidad

La galería permitirá:

- Ampliar fotografías.
- Navegar entre imágenes.
- Cambiar imagen mediante miniaturas.
- Soporte para dispositivos táctiles.

---

## Reglas

Las imágenes deberán mantener la misma proporción.

Nunca deberán deformarse.

La imagen principal deberá cargarse primero.

Las demás utilizarán Lazy Load.

---

# Colores

## Objetivo

Mostrar claramente los colores disponibles para cada modelo.

---

## Comportamiento

Cada color mostrará:

- Nombre.
- Muestra de color.
- Fotografía correspondiente.

Si un color no tiene fotografía, se mostrará una imagen de referencia.

---

# Medidas

Cada producto mostrará:

- Ancho.
- Fondo.
- Alto.

Cuando aplique:

- Medidas como sofá.
- Medidas como cama.
- Área recomendada.

Las medidas deberán representarse también mediante un esquema gráfico.

---

# SEO del producto

Cada producto tendrá:

- URL única.
- Meta Title.
- Meta Description.
- Open Graph.
- Schema.org Product.
- Texto ALT en todas las imágenes.

Nunca existirán dos productos con contenido duplicado.

---

# Administración

Cada producto deberá permitir administrar:

- Nombre.
- SKU.
- Categoría.
- Fotografías.
- Colores.
- Medidas.
- Descripción corta.
- Descripción completa.
- Especificaciones técnicas.
- Estado.
- Producto destacado.
- Productos relacionados.

Sin modificar el código.

---

# Automatización futura

La página deberá prepararse para integrarse con el CRM.

Cada consulta enviada desde esta página deberá registrar automáticamente:

- Producto consultado.
- Fecha.
- Hora.
- Nombre del cliente.
- Teléfono.
- Correo.
- Origen.
- Campaña.
- URL de origen.

---

# Criterios de aceptación

La página estará terminada cuando:

- Explique completamente el producto.
- Muestre fotografías de calidad.
- Permita consultar colores y medidas.
- Facilite el contacto por WhatsApp.
- Esté optimizada para SEO.
- Sea completamente administrable.

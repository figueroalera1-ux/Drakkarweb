# UI COMPONENT LIBRARY

Versión: 1.0

---

# Objetivo

Este documento define todos los componentes reutilizables que conforman la interfaz de Tiendas Drakkar.

El objetivo es que ningún componente sea diseñado dos veces.

Toda la plataforma deberá construirse reutilizando componentes.

Cada componente deberá ser independiente, reutilizable, escalable y fácil de mantener.

---

# Filosofía

Cada componente deberá cumplir cuatro reglas.

• Resolver un único problema.

• Ser reutilizable.

• Ser adaptable.

• Mantener consistencia visual.

Nunca deberán existir dos componentes distintos que hagan exactamente la misma función.

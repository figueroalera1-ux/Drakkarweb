# HERO SLIDER

Versión: 1.0

---

# Objetivo

El Hero Slider será el componente más importante de Tiendas Drakkar.

Durante los primeros cinco segundos deberá comunicar claramente:

• Qué vende Tiendas Drakkar.

• Por qué genera confianza.

• Qué debe hacer el visitante.

No será únicamente un carrusel de imágenes.

Será una herramienta comercial.

---

# Filosofía

Cada diapositiva deberá vender una sola idea.

Nunca deberá intentar comunicar demasiada información.

El visitante deberá comprender el mensaje en menos de cinco segundos.

---

# Administración

El Hero deberá ser completamente administrable.

No deberá ser necesario modificar código para cambiar campañas.

Cada diapositiva deberá permitir editar:

• Imagen de escritorio.

• Imagen móvil.

• Título.

• Subtítulo.

• Texto descriptivo.

• Botón principal.

• Botón secundario.

• URL del botón principal.

• URL del botón secundario.

• Orden.

• Estado (Activo / Inactivo).

---

# Comportamiento

El Hero deberá permitir:

• Reordenar diapositivas.

• Activar o desactivar campañas.

• Programar campañas futuras.

• Mostrar una sola diapositiva si únicamente existe una activa.

---

# Contenido

No deberán existir más de cinco diapositivas activas.

La primera diapositiva será siempre la campaña principal.

---

# Primera campaña

La primera campaña deberá transmitir:

Confianza.

No descuentos.

No promociones.

No urgencia falsa.

---

# Segunda campaña

Presentará el producto estrella.

Actualmente:

Sofá Cama Portugal.

---

# Tercera campaña

Presentará la venta de mayoreo.

Invitará a distribuidores.

---

# Cuarta campaña

Mostrará el respaldo de Muebles Vikingo.

Sin ocultar que Tiendas Drakkar opera de manera independiente.

---

# Quinta campaña

Podrá utilizarse para campañas temporales.

---

# Diseño

Las fotografías ocuparán la mayor parte del espacio.

El texto nunca cubrirá completamente el producto.

Siempre deberá existir excelente contraste.

---

# Responsive

Cada diapositiva tendrá:

Imagen para escritorio.

Imagen para tablet.

Imagen para móvil.

Nunca se utilizará la misma imagen recortada automáticamente.

---

# Rendimiento

Las imágenes deberán cargarse progresivamente.

La primera diapositiva tendrá prioridad de carga.

Las siguientes se cargarán bajo demanda.

---

# Accesibilidad

Todos los botones deberán ser accesibles mediante teclado.

Todas las imágenes deberán tener texto ALT.

El slider deberá poder pausarse.

---

# Regla principal

El Hero deberá vender confianza.

Después vender productos.

Nunca al revés.
